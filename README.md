# meble

Lokalny projekt: katalog płyt z meble.pl oraz mostek SketchUp.

- `sketchup_chat_bridge` — klon [kiermasp/sketchup-chat-bridge](https://github.com/kiermasp/sketchup-chat-bridge) (własna historia gita).
- `server` — API NestJS, które pobiera dostępność płyt i zapisuje ją w Postgresie.
- `docker-compose.yml` — Postgres i API. Uruchamiaj z tego katalogu.

Szczegóły instalacji, testów i compose są w sekcji poniżej i będą uzupełniane wraz z kodem serwera.
